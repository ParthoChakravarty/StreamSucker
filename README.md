# StreamSucker

**StreamSucker** is a video downloader that allows you to download videos in three different ways.

## Features

- **Full Video Download** – Download the entire video.
- **Section Download** – Download a specific section of a video by specifying the start and end timestamps.
- **Frame Extraction** – Extract individual frames from a video.

## Built With

StreamSucker uses the following tools under the hood:

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) – For downloading videos from supported websites.
- [FFmpeg](https://ffmpeg.org/) – For video processing, section extraction, and frame extraction.

## Requirements

Make sure the following tools are installed and accessible from your system's PATH:

- yt-dlp
- FFmpeg
